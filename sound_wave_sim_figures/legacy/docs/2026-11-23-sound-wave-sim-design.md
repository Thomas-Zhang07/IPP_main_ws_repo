## 1. Intent

The report concludes that grating lobes are unavoidable at 10.5 mm pitch
(d/λ = 1.22 at 40 kHz) and that board B's 5.25 mm half-pitch y offset is what
cancels the 54.75° lobe. The instructor asked for simulation figures of the
candidate board layouts so the choice of arrangement can be judged by
its leak, not by bench intuition.

Goal: for each layout, produce figures that show

1. the far-field directivity (where energy goes, and how strong the 54.75°
   lobe is), and
2. the near-field pressure distribution (what actually happens in the room,
   including the interaction between boards).

Success: the layouts can be compared side by side on one metric chart,
and the reasoning "interleaving kills the 54.75° lobe" is visible in the
figures themselves.

## 2. Non-goals

- No report writing, no Feishu upload.
- No electronic steering studies. Every board is broadside (phase 0) in its
  own frame; only the mechanical arrangement changes. Steering is a later
  study.
- No measured calibration / phase-error data. This is an ideal model, and the
  figures must say so.
- No real-time parameter playground. Figures are generated by a script;
  the HTML 3D views are rotatable but not reconfigurable.

Anti-goals: a figure that cannot distinguish the layouts; a pretty 3D page
with no quantitative content.

## 3. Physics model

Held constant for every layout:

| Quantity | Value |
|---|---|
| Grid per board | 16 × 16 = 256 elements |
| Pitch | 10.500 mm |
| Element aperture span | 157.500 mm |
| Board outline | 168.402 × 185.092 mm (from the fixture drawing) |
| Carrier | 40 kHz, c = 343 m/s, λ = 8.575 mm, k = 2π/λ |
| Element | circular piston, diameter 10.000 mm, baffled |
| Amplitude | uniform (1 per element) |
| Phase | 0 rad on every element (broadside in board frame) |

Element directivity: `D(β) = 2 J1(x)/x`, `x = π d sin β / λ`, with `β` the
angle between the element normal and the observation/field direction; zero
for β > 90° (the PCB baffles the rear). Every element uses its **own** board
normal, which matters for the tilted layouts. Without this factor every
grating lobe plots at 0 dB and the layouts become indistinguishable; with it
the single-board 54.75° lobe sits near −13 dB.

Far field on a direction-cosine grid `u = (u_x, u_y, u_z)` over the unit
disk (this samples the forward hemisphere evenly and resolves sub-degree
main lobes; `dΩ = du_x du_y / u_z` is used for every power integral):

```
p(u) = Σ_i A_i · D_i(u) · exp( i k (u · r_i) + i φ_i )
```

Near field (field point `r`):

```
p(r) = Σ_i A_i · D_i(r) · exp( i k |r − r_i| + i φ_i ) / |r − r_i|
```

`D_i(r)` uses the angle of `(r − r_i)` against element i's normal. Both are
discrete sums over ≤ 768 elements — no paraxial or Fraunhofer assumption, so
the near-field figure is valid from the array plane outward.

All levels are normalized to the global peak and shown in dB, floored at
−40 dB.

### Metric conventions (fixed for every layout and both studies)

- Domain: the **global +z hemisphere** only, because the listener is in front.
  Tilted layouts that send power outside it lose that power from every
  forward metric; their on-axis level is reported too, so a layout that aims
  away from the listener cannot score well by accident. `facing` radiates
  into two opposite half-spaces, so it has **no far-field metrics** (n/a in
  the chart) and is represented only by near-field figures.
- `lobe_54_75_db` — the level at the four axial grating directions
  `θ = asin(λ/d) = 54.75°`, `φ = 0/90/180/270°`, maximum of the four. This is
  the report's claim, measured where the lobe actually is.
- `band_max_db` — the maximum over the whole hemisphere in the 50–60°
  elevation band. This is the robustness number: it does not reward a narrow
  notch that merely pushes energy into the shoulders. Both are reported
  because they can disagree by tens of dB.
- `band_energy_pct` — fraction of forward-hemisphere power in 50–60°;
  `leak_60_pct` — fraction above 60°.
- `peak_sidelobe_db` — maximum outside the main-lobe cone (15° around the
  global maximum); the 50–60° band is **not** excluded, so this and
  `lobe_54_75_db` can coincide for a bad layout.
- `bw6_xz`, `bw6_yz` — −6 dB width on the φ = 0 and φ = 90° great circles.
- `DI` — forward-hemisphere directivity index as defined in §8.
- `on_axis_db` — level at β = 0, for every layout.

## 4. Layout definitions

Global frame: x horizontal, y vertical, z forward (away from the array).
Board local frame: columns along x_l, rows along y_l, normal +z_l; emitter
(r, c) at `(c·d, r·d, 0)`.

1. **single** — one board, normal +z, centred on the origin.
2. **v150** — two boards, hinged at their **PCB inner edges**, which are
   butted on the vertical line x = 0, z = 0. The inner element columns are
   then 10.902 mm apart (±5.451 mm), y rows aligned across both boards. Each
   board is yawed about the hinge line so the included angle between the
   faces is **150°** (±15°). The boards open **forward** toward the listener
   (their planes extend to z > 0); the normals converge.
3. **v120** — same construction, **120°** (±30°).
4. **coplanar_butt** — two boards, same plane, **10.902 mm** element seam
   (PCB edges touching; the two facing margins are 5.496 + 5.406 mm), no y
   offset. This is the physical butted baseline, not an ideal 10.5 mm
   lattice; the top-view sketch shows real board outlines.
5. **coplanar_gap** (current) — seam 15.750 mm, board B y offset +5.250 mm,
   PCB edge gap 4.848 mm, exactly as `mounting_mechanics/README.md`.
6. **facing** — two boards coaxial and parallel, normals opposite, 400.000 mm
   apart, bottom edges aligned in y. Board A at z = 0 (normal +z), board B at
   z = 400 mm (normal −z). Near-field only (§3).
7. **concave3** — three boards: centre board flat, wings hinged at its PCB
   left and right edges (element seam 10.902 mm), each yawed ±30° forward
   (concave side toward the listener, `\_/` in top view). 48 × 16 aperture.
8. **coplanar3** — three boards in one plane, seam 15.750 mm (the current
   gap), no y offsets. The reference point of the 3-board study (§8).
9. **pair_seam_only** (control) — seam 15.750 mm, **y offset 0**. Separates
   the effect of the 1.5-pitch x seam from the 5.250 mm y offset: the seam
   alone nulls the φ = 0/180° lobes, the offset alone nulls φ = 90/270°.
   Without this control the figures would credit one parameter for the
   other's work.

The 2-board case is not taken on trust: the current coplanar 15.750 / 5.250
geometry (layout 5) is the reference, and §9 searches the 2-board space to
establish whether it is Pareto-optimal or whether a better pair exists.

Calls made here (all are script parameters, so cheap to change):
V angles are 150° and 120° as requested; concave wing angle is 30° (no value
was given); facing distance is 400 mm; layout 8 uses the current 15.75 mm
seam; amplitude is uniform.

For every layout the script also draws a small top-view of the board planes,
so the geometry is never ambiguous.

## 5. Figures

Directory per configuration, `figures/<id>/`:

### `farfield.png`

- (a) Hemisphere map: azimuth −90…+90° × elevation 0…90°, |p| in dB, a
  dashed arc at 54.75°.
- (b) Cartesian cuts through the x–z and y–z planes (0…90° versus −40…0 dB),
  with the 54.75° line marked. Cartesian was chosen over polar after review:
  polar compresses a sub-degree beam into the apex and hides the null.
- Inset: top view of the boards with normal arrows.

### `nearfield.png`

- (a) x–z plane at array mid-height, (b) x–y listening plane at z = 300 mm,
  (c) y–z plane at x = 0 (shows the vertical grating lobes and the y offset),
  (d) a zoom on the seam plotting instantaneous pressure Re(p), which makes
  wavefront continuity and the half-pitch phase inversion visible.
- Panels (a)–(c) share one normalisation (the x–z peak); 1 m and 300 mm
  markers.

For `facing`, panel (a) covers the cavity x = −0.5…0.5 m, z = 0…0.4 m, and
panel (b) is the mid-cavity plane z = 200 mm.

### `view3d.html`

One page per configuration, rotatable (Three.js + OrbitControls, CDN, no
build step):

- far-field surface `r ∝ (L + 40)/40`, coloured by dB, boards drawn under it;
- near-field as three orthogonal textured planes (x–z at y = 0, x–y at
  z = 300 mm, y–z at x = 0) with the same colour map;
- a toggle between the two modes, a dB colour legend, axis labels, and the
  layout name + key numbers.
- `web/index.html` links all nine.

### Optimization study outputs (`figures/study2/`, `figures/study3/`, `figures/optimal3/`)

- `study2/scan.png` — DI and leak metrics over seam gap × y offset at V yaw
  0°, uniform and Hann, with the current pair marked.
- `study2/yaw.png` — the same over V/wing yaw for the best seams.
- `study3/scan.png` — metrics versus a single seam gap, for each y-offset

- `study3/heatmap.png` — A–B gap × B–C gap, because unequal gaps de-periodise

- `study2/pareto.png`, `study3/pareto.png` — leak above 60° versus −6 dB

- `optimal3/farfield.png`, `optimal3/nearfield.png`, `optimal3/view3d.html` —

### `comparison.png`

The punchline chart: for all nine configurations, bars for

- 54.75° lobe level (peak in the 50–60° band),
- peak sidelobe outside 15° of the main lobe,
- leak fraction: fraction of radiated power above 60° from broadside,
- −6 dB beamwidth in the x–z plane.

Also `metrics.csv` with these plus −6 dB beamwidth in y–z, directivity index

## 6. Code structure

```
sound_wave_sim_figures/
  sim/
    constants.py   frequency, sound speed, pitch, element diameter, board size
    geometry.py    Board dataclass (origin, yaw, pitch, roll) -> positions,
                   normals; the nine layout builders
    field.py       far_field(), near_field_plane(), metrics(), in chunks so
                  768 elements x full grid fits comfortably in RAM
    render_png.py  matplotlib figures (300 dpi, no seaborn, colour-blind-safe
                  cmap), top-view board sketch
    optimize.py    2- and 3-board sweeps, refinement, Pareto fronts, pick
    export_web.py  writes view3d.html + binary field data (float32 .bin)
    run_all.py     builds every layout, writes figures/, metrics.csv,
                   web/index.html
  figures/  <id>/{farfield.png,nearfield.png}
  web/      <id>/index.html + data/*.bin
  metrics.csv
  README.md  how to run, what is modelled, what is not
```

Python 3 + numpy + matplotlib only (`requirements.txt`). No import from
`demo/`: the demo model is restricted to planar 16 × 16 and would be bent out
of shape by the tilted layouts. Constants are copied with a comment pointing
at `demo/emitters.py`.

## 7. Validation

- Single board, broadside, uniform: **`lobe_54_75_db` must land at
  −12.8 ± 0.5 dB**, first sidelobe −13.3 dB, and the far-field cut must match
  `demo/array_factor.compute_array_factor_pattern` with piston weighting to
  within 0.2 dB when both are sampled on the same directions.
- `coplanar_gap` must suppress the **exact** 54.75° lobe (all four axial
  directions) by ≥ 10 dB relative to `coplanar_butt` — the report's claim. The
  control `pair_seam_only` must leave the φ = 90/270° lobe intact (within
  1 dB of the butted level) while nulling φ = 0/180°, proving the attribution
  in the report is right about the offset but incomplete about the seam: the
  1.5-pitch seam nulls the x-axis lobe, the 5.25 mm offset nulls the y-axis
  lobe.
- The 50–60° **band** metrics are expected to improve far less than the
  exact-lobe number (the null pushes energy into shoulders). That is a
  physical result, not a model error; it must be reported, not tuned away.
- Reciprocity/symmetry spot checks: single board symmetric under x ↔ −x;
  coplanar layouts symmetric in azimuth.

## 8. 2- and 3-board optimization

Two questions, one method: does the current pair deserve to be called best,
and does any 3-board arrangement beat it?

With three boards the half-pitch trick cannot null the 54.75° lobe the way the
pair does — at the lobe, two boards sit on one lattice and one on the other,
so the best a pure interleave can do is roughly −9.5 dB. Both searches are
therefore over **geometry that de-periodises the lattice**, plus amplitude
taper, not over interleaving alone.

Parameters and ranges:

| Parameter | 2-board range | 3-board range | Step |
|---|---|---|---|
| seam gap (one for 2 boards, A–B and B–C for 3) | 10.902 … 26.250 mm | same, both independent | 0.525 mm coarse, 0.131 mm refine |
| y offset | 0 … 10.500 mm | each 0 or 5.250 mm (only these differ mod 10.5) | 0.525 mm / discrete |
| V / wing yaw | 0 … 45° | 0 … 30° | 5° |
| amplitude | uniform, Hann (separable, 2-D) | same | discrete |

Objective, maximised: forward-hemisphere directivity index
`DI = 4π|p_max|² / ∫_{hemisphere}|p|² dΩ`.

Reported alongside, and used for the Pareto curve: `lobe_54_75_db`,
`band_max_db`, `band_energy_pct`, `leak_60_pct`, peak sidelobe outside 15° of
the main lobe, −6 dB beamwidth in x–z and y–z, element count.

Procedure: coarse full-factorial sweep → take the Pareto front → local
refinement around its knee → render the winning geometry as a full figure set.
Every candidate is evaluated with the same 2° hemisphere grid as §3, so
numbers are comparable across both studies. The current pair is evaluated by
the same code path and marked on every scan, heatmap and Pareto plot.

What "optimal" will mean here, stated in the figures: Pareto-optimal within
the searched ranges under the ideal model (§3). No claim of a global optimum
in the continuum, and no claim that survives phase errors, failed elements or
amplitude-code quantization; those are bench questions.

Acceptance:

- 2-board: the current 15.750 / 5.250 geometry must sit on the Pareto front
  and within 0.2 dB of the best DI in the space. If it does not, the figures
  name the better pair instead — that is a finding, not a failure.
- 2-board attribution: `pair_seam_only` is evaluated and plotted with the
  current pair, so the seam's effect and the offset's effect are separately
  visible.
- 3-board: an arrangement is worth building only if it beats the current pair
  on DI at equal or better −6 dB beamwidth. `pareto.png` and
  `comparison.png` must show that comparison explicitly, including the case
  where nothing beats the pair.

## 9. Risks / what is left to the builder

- Runtime: near-field 2D grids (~750 × 800) × 768 elements is ~4.6 × 10^8
  complex ops per panel; chunk over field points, expect seconds to a minute
  per configuration on CPU. Cache raw arrays under `data/` so re-rendering
  does not recompute.
- 3D HTML file size: ship float32 binary grids (compressed by simple
  quantization to uint8 dB) so each page stays under a few MB.
- Three.js is loaded from cdn.jsdelivr.net at an exact version; no build
  tooling.
- The absolute SPL is not modelled (no drive level), only relative dB.
