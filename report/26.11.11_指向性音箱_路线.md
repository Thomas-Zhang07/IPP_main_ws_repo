# Directional Speaker Demo

## 1. 提升指向性

### 主机 Python

- 抽稀/密度加权：按 Hann/Gaussian 选阵元；栅瓣降 10–20 dB，增益 −3 dB，主瓣 ×√2。
- 相位抖动：每阵元 ±1–2 档随机相位；打散栅瓣，成本最低。
- 相位-only 优化：坐标下降/SA；压旁瓣、加零陷；旁瓣 −5–15 dB，零深 −20–30 dB。
- 相位校准：测逐通道误差，主机预补偿；主瓣 +1–3 dB。
- 结论：能明显压旁瓣/栅瓣，但幅度只有二值，效果有上限。

### FPGA

- FPGA 侧唯一算算法的：逐通道 duty 幅度加权（`DutyLine` 原型；`PhaseLine` 加 duty + 脉冲居中）。

### 硬件

- ≤λ/2 间距（≤4.3 mm）：根治栅瓣。
- 宽频换能器：决定音频带宽。
- 逐通道 DAC/驱动：真正连续幅度。
- 主瓣 3° 是孔径极限，算法不能显著变窄。

### 建议

1. 测基线方向图 + 换能器带宽。
2. 相位校准。
3. 试抽稀/抖动/相位优化。
4. 再上 duty 幅度固件。

## 2. 做流播放

### MVP

主机流任意单声道音频 → FPGA FIFO + sigma-delta → 现有波束。

- 8 kHz / 8-bit / 单声道（先跑通，再上 16 kHz）
- 256 kbaud / 25.6 kB/s
- 1 kB FIFO / 128 ms
- 一阶 sigma-delta @5.12 MHz
- 延迟 100–300 ms，窄带音质
- 不需要新硬件

### 要做的事

1. UART：`g_CLKS_PER_BIT` 133→20；`RSSFilter_1` TAPS 8→2。
2. 协议：新增 `0xCC` 音频包。
3. FPGA：1 kB FIFO + sigma-delta + `stream_en`。
4. 资源：删 SignalTap；不够换 EP4CE10/15。
5. 主机：WAV/麦克风 → 8-bit → 256 样本块；独立线程 + 环形缓冲。
6. 测试：回环 → 正弦 → WAV → 麦克风 → 边放边转。

### 硬件

- MVP 不需要；确认 USB 串口支持 256k（FTDI 稳，CH340 看驱动）。
- 可选 MCU 音频桥（STM32/ESP32/Teensy）。
- 后续 hi-fi：codec/DAC + 模拟 AM、宽频换能器、≤λ/2 阵列。

### FIFO

先进先出缓冲，解耦 UART 写入和 8 kHz 读出，吸收主机抖动。

1 kB = 1024 样本 = 128 ms @8 kHz；空则静音，满则丢包或降速。

### 协议

现有相位帧：

```text
0xFE | 256 × phase | 0xFD
```

新增音频包：

```text
0xCC | len_hi | len_lo | N × sample | checksum
```

- 长度前缀避免样本字节误触发 `0xFE/0xFD/0xC8`。
- 包与包之间可插相位帧，实现边放边转。

### 带宽

| 波特率 | 有效 | 8 kHz | 16 kHz |
|---|---|---|---|
| 38400 | 3.84 kB/s | 不够 | 不够 |
| 256k | 25.6 kB/s | 31% | 62.5% |
| 512k | 51.2 kB/s | 16% | 31% |

### 里程碑

1. UART 回环 256k / TAPS=2（1–2 天）
2. FIFO + sigma-delta，1 kHz 正弦（3–5 天）
3. 8 kHz WAV（1 周）
4. 麦克风 + 16 kHz/512k（1–2 周）
5. 边放边转（3–5 天）

## 3. 结论

- 指向性：主机算法 + 校准先做；duty 幅度是下一步；3° 主瓣不变。
- 流播放：8–16 kHz/8-bit/256k 可做，不需要新硬件，约 2–4 周。
- 高保真：受换能器带宽和 10 mm 间距限制，需换硬件。
