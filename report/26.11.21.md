## 2. Per-channel duty amplitude

- Each frame is 258 bytes: 0xFE + 256 payload (载荷) bytes (one per channel) + 0xFD. The 25 µs carrier (载波) at 40 kHz is split into 16 phase bins of 1.5625 µs; 256 PhaseLine instances output high between on-step and off-step, so the width is (off − on) mod 16 bins and the fundamental amplitude (基波幅度) follows sin(π·width/16), maximum at 8 bins, i.e. 50 % duty (占空比). A full-width pulse starts at phase+1 and ends at phase+9, centred on phase+5. Narrowing the pulse without moving the start would shift that centre, so an amplitude change would drag the phase and pull the beam. The RTL therefore shifts on-step later by lead = 4 − width/2, keeping every width centred on phase+5: amplitude changes leave the phase untouched.
- Bits 7–4 of each byte are the amplitude code (幅度码) 0–15 and bits 3–0 are the phase bin 0–15, so one channel is exactly one byte. Codes 0 and 15 both give the full 8-bin width: 0 is kept as full scale for backward compatibility (向后兼容), otherwise old frames (high nibble 0) would go silent. Codes 1–14 map to widths 1–7 by integer division, (code + 1) / 2, two codes per width. 0x10 is a separate off code (关断码): the RTL turns it into width 0 (on = off) and PhaseLine holds the channel low — without that case 0x10 would decode as amplitude code 1.
- Fit: primary 5,622 / 6,272 LE (90 %), secondary 5,679 / 6,272 (91 %).

## 3. Dual board

0.5 mm gap

Grating lobes (栅瓣) are unavoidable because clean sampling needs d ≤ λ/2 (4.3 mm at 40 kHz). Board B's half-pitch offset (半节距偏移) cancels the 54.75° lobe.

- (image) `assets/11.21/setup.png` — layout: 15.75 mm seam, 4.848 mm edge gap, 5.25 mm y offset, 390 mm base.
- When the primary's carrier counter (载波计数器) reaches zero it sends a ~195 ns pulse on MISC_D to the secondary's MISC_A, once every 25 µs. The secondary samples it with its 50 MHz master clock (主时钟); 5.12 MHz is divided from it by 128/1250 (ratio 9.77, not 10), removes metastability (亚稳态) with two flip-flops (触发器), then delays it by 0–255 trim (微调) steps of 20 ns (≈ 0.288° at 40 kHz) — sampling at 5.12 MHz alone cannot resolve sub-period timing. The delayed edge becomes a toggle (翻转信号) and is re-synchronized into the 5.12 MHz domain by two more flip-flops, producing a one-cycle pulse; a toggle is used because a 20 ns pulse could be missed by the slow clock. That pulse reloads the carrier counter to SYNC_LOAD = 17, a constant that absorbs the fixed synchronizer (同步器) latency (延迟) and replaces the 71 of the retired square-wave + majority-filter scheme. The 8-bit trim resets to 127 (01111111), the midpoint that gives zero phase error in simulation; trim 0 and 255 sit about +13 and −13 clocks away.
- The trim command 0xE0 0x5A value is read only between frames, so a payload byte equal to 0xE0 cannot be mistaken for it.
- Board select: a 0xC0 or 0xC1 byte precedes each command/frame. 0xC0 enables the primary and disables the secondary; 0xC1 does the reverse, and the disabled board ignores the payload.
- Two independent UART links: primary CH340 (COM8), secondary FTDI (COM6), TX → port B, 38.4 kBaud.
- Both boards play the same mode, and a parallel mode change restarts both music players, so Little Star starts together.
- First verify carrier lock (载波锁定) by scoping primary MISC_D (195 ns pulse every 25 µs at counter 0) against secondary MISC_A; if it drops or jitters, the secondary stops reloading and the boards drift. Even locked, residual skew (相位偏差) leaves a static phase offset that smears the beam if trim is left at 127. Set both arrays broadside (正前方), sweep secondary trim 0–255 in steps of 8 (20 ns ≈ 0.288° per unit, so 8 units ≈ 160 ns ≈ 2.3°), and tune for the deepest null (零点) at 54.75° — null depth is far more sensitive to inter-board phase than the main-lobe (主瓣) peak. Lock that value and measure the pair at 1–3 m.
