## 3. PulseExpander 毛刺（修复前 / 修复后）

0xFD 之后 Distribute 把 swap_out 一直保持高；旧扩展器在同一个时钟沿既重装计数器又递减，输出每 17 个 CLK_8 掉 1 拍。LatchBuffer 用 COUNT(2) 采样后，每 136 个 CLK_8（≈26.56 µs）产生一次假 swap，PhaseLine 反复交换双缓冲，帧结束后相位保不住，DATA 静不下来。

### 现象：旧代码

- RTL（tb_glue）：swap_exp 周期性掉低，swap_e 反复出现上升沿；帧后 DATA(0) 不静默，测试 FAIL。
- 门级网表（tb_top，simulation/modelsim/QuadrupleBuffer.vho）：帧后 200 µs 内 DATA(0) 仍有 8 个边沿，报 FAIL：`DATA(0) quiet after channels 0..7 off, edges=8`。
- 节拍：毛刺 17 × CLK_8 = 3.32 µs；采样后 136 × CLK_8 = 26.56 µs 一次，约等于一个 25 µs 驱动周期。

### 根因：旧代码

VHDL 同一进程内对同一信号的多次赋值以最后一次为准。pulse_in 为高时先重装 sCounter，随后又被 sCounter-1 覆盖，计数器继续递减；减到 0 的那一拍输出被拉低，下一拍才重新拉高。

```vhdl
if (pulse_in = '1') then
    sCounter <= OUTPUT_LENGTH_CYCLES;
end if;

if (sCounter = 0) then
    s_pulse_out <= '0';
else
    s_pulse_out <= '1';
    sCounter <= sCounter - 1;
end if;
```

### 修复：新代码

输入为高时输出保持高、只重装不递减（elsif 分支）；对真正的单拍输入，拉伸行为不变。修复提交 58b2df9，文件 fpga_code/src/PulseExpander.vhd。

```vhdl
if (pulse_in = '1') then
    sCounter <= OUTPUT_LENGTH_CYCLES;
    s_pulse_out <= '1';
elsif (sCounter = 0) then
    s_pulse_out <= '0';
else
    s_pulse_out <= '1';
    sCounter <= sCounter - 1;
end if;
```
